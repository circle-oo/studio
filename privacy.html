개인정보처리방침

시행일: 2026-09-27

If Science Studio(이하 "도구")는 운영자 한 사람이 자기 컴퓨터에서만 실행하는 개인용 도구입니다.

수집·이용하는 정보

  • Google(YouTube Data API): 운영자 본인 계정의 OAuth 토큰. 채널 정보 확인(youtube.readonly)과 영상 업로드(youtube.upload)에만 사용합니다.
  • Instagram API: 운영자 본인 계정의 액세스 토큰. 계정 확인과 릴스 게시에만 사용합니다.

보관과 공유

토큰은 운영자 컴퓨터의 로컬 파일에만 저장되며 어떤 서버로도 전송·판매·공유하지 않습니다. 제3자 사용자의 정보는 수집하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(Limited Use 요구사항 포함)을 따릅니다.

삭제

로컬 토큰 파일을 지우거나 Google 계정(보안 → 타사 액세스)과 Instagram 설정에서 권한을 철회해 언제든 접근을 해제할 수 있습니다.

Summary

This personal tool stores the owner's own YouTube/Instagram OAuth tokens only on the owner's computer, uses them solely to read the owner's channel info and upload the owner's videos, and never transmits, sells or shares data. Use of information from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
